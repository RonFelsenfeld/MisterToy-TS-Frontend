# Mister Toy 🧸

## Mister Toy Description

Mister Toy is your ultimate online destination for all things fun and playful! Whether you're searching for the perfect toy, keeping an eye on the latest trends, or just exploring for fun, we've got you covered. With a vibrant interface, powerful features, and a sprinkle of joy, Mister Toy is here to make your toy-shopping experience delightful.

**This is the frontend repository of Mister Toy, backend is right [here](https://github.com/RonFelsenfeld/MisterToy-TS-Backend).**

## Main Features

### Toys Management
- **Discover Toys**: Browse an exciting collection of toys that will bring a smile to kids and kids-at-heart alike.
- **Filter and Sort**: Easily find your favorites by filtering categories or sorting by price and more.
- **Admin Superpowers**: Admins can seamlessly edit or remove toys to keep the collection fresh and up-to-date.

### Authentication
- **Join the Fun**: Sign up or log in to personalize your experience.
- **Easy Exit**: Securely log out whenever you want.
- **Admin Magic**: Unlock exclusive admin features to manage toys effortlessly.

### Translation
- **Global Joy**: Switch between English and Hebrew for a fully localized and inclusive experience.

### Statistics Dashboard
- **Data, but Make It Fun**: Enjoy colorful charts and graphs that bring store stats to life.

### Branched Map
- **Find Us**: Check out our interactive map to locate your nearest Mister Toy store branch and plan your visit.

## Technologies

- TypeScript
- React JS
- Redux Toolkit
- SASS

## Packages

- apollo/client - For communicating with the server (built with GraphQL).
- chart.js - For displaying statstics charts.
- crypto-js - For authentication tokens.
- i18next - For translation support.
- leaflet - For the branches map.

## Local Installation

**1. Clone the repo:**

```
git clone https://github.com/RonFelsenfeld/MisterToy-TS-Frontend.git
```

**2. Navigate to the project directory and install dependencies:**

```
cd MisterToy-TS-Frontend
npm install
```

**3. To run client:**

```
npm run dev
```

**4. Install [MisterToy-TS-Backend](https://github.com/RonFelsenfeld/MisterToy-TS-Backend) locally and run the server.** <br>
_(Follow the instructions in it's README file)_
